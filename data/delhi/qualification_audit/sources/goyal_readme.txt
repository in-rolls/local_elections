Readme file – “Local political representation as a pathway to power: A natural experiment in India”
Date – 17th May 2023

The replication folder contains the following folders – 
1.	Readme file
2.	1_RawData – contains raw data files
3.	2_ProcessedData  - contains data analysis files generated using script DataAnalysis.R 
4.	3_Scripts – contains scripts that generate data for analysis and two scripts (R and do file) that replicate all 
tables and figures in the main manuscript and the appendix. 
5.	4_Output – contains all the output such as graphs and analysis tables that reported in the manuscript and 
appendix
6.	5_LogFiles – contains the log files for each script file.
7.	6_Maps - contains the Delhi ward map boundaries for 2012 elections downloaded from Datemeet public website in July 2010.
7.	Codebook– codebook of all the analysis datasets available in CSV (autogenerated) and PDF file.
8.	Codebook_TCPD_GE_Delhi_2020-2-23.pdf – codebook of the publicly available dataset 
TCPD_GE_Delhi_2020-2-23.csv

Raw data: Contents of 1_RawData. Raw data files that include data that are taken directly from various sources 
such as Trivedi Centre for Political Data and Delhi’s state election commission website accessed at various points as 
well as original data collected using original field surveys. Some data was also taken from the AJPS replication 
dataverse. I have retained original identifiers to ensure that these datasets can be merged with other publicly 
available datasets for both greater transparency as well as to help scholars who may wish to use this dataset. More 
details are attached below for every data source.

State constituency or State constituency-candidate level datasets
1.	TCPD_GE_Delhi_2020-2-23.csv – State level candidacy data downloaded from “TCPD Indian Election 
Dataset (TCPD-IED), 1951–1962.” Trivedi Centre for Political Data, Ashoka University. Website - 
https://tcpd.ashoka.edu.in/indian-elections-dataset-1951-1962/ . This data was download in February 2020. 
Unique identifier is the year, position, constituency_number. The code book is titled 
“Codebook_TCPD_GE_Delhi_2020-2-23.pdf”
Data Citation: Ananay Agarwal, Neelesh Agrawal, Saloni Bhogale, Sudheendra Hangal, Francesca Refsum Jensenius, Mohit Kumar, Chinmay Narayan, Basim U Nissa, Priyamvada Trivedi, and Gilles Verniers. 2021. “TCPD Indian Elections Data v2.0", Trivedi Centre for Political Data, Ashoka University.
Codebook Citation: Ananay Agarwal, Neelesh Agrawal, Saloni Bhogale, Sudheendra Hangal, Francesca Refsum Jensenius, Mohit Kumar, Chinmay Narayan, Basim U Nissa, Priyamvada Trivedi, and Gilles Verniers. 2021. “TCPD Indian Election Data Codebook v2.0", Trivedi Centre for Political Data, Ashoka University.
Note that the folder has a redacted codebook document which only contains pages 1-13 that are relevant for the paper. 
For the full un-abridged version please refer to the lokdhaba website.


2.	AE_WomenAffidavits.xls –  State-level affidavit data taken from the coordinator of the data team at TPCD 
directly in Dec 2020. Unique identifier is the year, position, constituency_number.

Municipal constituency  or Municipal constituency-candidate level datasets 

3.	CandidateElectionData_original.xlsx – Municipal-level candidacy data, electoral data, and candidate 
affidavit data was digitized from pdfs available on SEC https://sec.delhi.gov.in. The SEC website was last 
accessed in Feb 2020. Unique identifier is election, commonname (which reflects the municipal ward 
number), and eci_pos. Candidate affidavit data for municipal level candidate was also manually added 
during the digitization. 


4.	AE_WomenCasteBackground.xlsx– Data on state-level women’s caste and family background was added 
through data file made available by coordinator of the data team at TPCD in Dec 2020.  Unique identifier is 
the year, position, constituency_number.

5.	Municipal_TurnoutMappingResData.csv – Ward level data on turnout, reservations, and mapping with AE 
taken from SEC https://sec.delhi.gov.in. The SEC website was last accessed in Feb 2020. Unique identifier 
is election, commonname, and eci_pos.

6.	CasteData_Lee2020_AJPS.xlsx – Data take from Karekurve-Ramachandra, Varun; Lee, Alexander, 2020, 
"Replication Data for: Do Gender Quotas Hurt Less Privileged Groups? Evidence From India", 
https://doi.org/10.7910/DVN/0QOVCH, Harvard Dataverse, V1, UNF:6:PoZdwNrbkenQ3kT5kJy3BQ== 
[fileUNF] Unique identifier is wardnumber, and year.

Manually merged dataset that contains information about which municipal candidates contested state-level 
elections.
7.	AE_WomenManualMatch.xls – This data creates histories of candidates careers for the universe of 
municipal and state-level candidates in the study period from 2007-2020. TCPD_GE_Delhi_2020-2-23.csv 
was manually merged with CandidateElectionData_original.xlsx using names of municipal and state 
candidate that were cleaned of titles and punctuations. Municipal candidates were matched to state-level 
candidates only if they shared the same assembly constituency. Internet searches and interviewing 
politicians/ party officials were done to reject false matches in cases where there was ambiguity. Unique 
identifier is the election, commonname, ACnumber.

Survey datasets – Activists (201-2022) and incumbent municipal politicians (2017) in Delhi were interviewed 
and the following anonymized datasets that remove all identifying information to locate respondents. 

8.	ActivistSurveyData.RData – Response data from original survey conducted with party activists in Delhi. 
Unique identifier is irrelevant.

9.	MunicipalCouncilSurvey.dta – Response data from original survey conducted with incumbent municipal 
councilors in Delhi. Unique identifier is irrelevant.


2_ProcessedData: The script DataPrep.R prepares the data for the analysis that are stored in 2_ProcessedData folder 
and generates the “codebook.csv” file. The raw data are at the state constituency- or municipal constituency-
candidate level and these are merged and aggregated to state-create constituency level variables that are in the 
processed data folder.

To match any analysis file with any state-level dataset the unique identifier is election year and acno or 
constituency_no and can be traced back to any of the publicly available state-level files. If the unit of analysis of the analysis data file is municipal constituency level or municipal constituency-
candidate level: 

1. To match with any state-level dataset the unique identifier is election year and acno or 
constituency_no and can be traced back to any of the publicly available state-level files.
2. To match with any municipal-level dataset the unique identifier is election year and local 
constituency number or commonname and can be traced back to any of the publicly available 
municipal-level files.

3_Scripts:  This folder contains all the scripts used to prepare and analyze the datasets.
Order of running the scripts 
1.	Run DataPrep.R – prepares analysis dataset
2.	Run DataAnalysis.R – analyses analysis dataset
3.	Run DataAnalysis_stata.do – analyses analysis dataset that are in DTA format


4_Output: This folder contains all the main result tables, appendix tables, and graphs that are in the manuscript or 
the appendix. Each file is labelled to match the main manuscript or appendix table number or figure number. All the tables and figures in the paper including appendix are replicated except for Figure 2 and Figure 3. 

Figure 2 and Figure 3 are illustrative spatial maps that are manually generated in QGIS using Delhi municipal ward maps obtained from the publicly available data meet website - https://github.com/datameet/Municipal_Spatial_Data/tree/master/Delhi and http://projects.datameet.org/Municipal_Spatial_Data/ - More details available in the description of 6_Maps folder below. The Delhi Legislative Assembly maps post-delimitation were obtained using proprietary ML Info maps from the Harvard Geospatial Library and cannot be publicly shared.
